# Terminal UNO：使用说明

跨平台终端多人联机 UNO 游戏。无需浏览器，玩家通过命令行加入其中一位玩家托管的房间。程序同时支持“开房（host）”和“加入（join）”，开房者既是服务器也是普通玩家。

> 技术栈：Go + Bubble Tea v2 + Lip Gloss v2 + TCP + JSON
> 平台：Windows / Linux / macOS
> 网络：局域网直连；跨网络使用 ZeroTier 连接房主
> 交付：一个可执行文件，同时支持开房与加入
> 游戏规则与额外细节以 [rule.md](rule.md) 为准。

---

## 1. 获取程序

三种方式任选：

- **GitHub Release 发布页**（推荐）：维护者发布版本（打 `v*` 标签）后，GitHub
  Actions 会自动为下列平台编译并上传到 Release 页，下载对应平台的可执行文件即可：
  - Windows（x64）：`uno-windows-amd64.exe` → 建议改名 `uno.exe`
  - Linux：`uno-linux-amd64`（x64）/ `uno-linux-arm64`
  - macOS（Intel）：`uno-darwin-amd64`
  - macOS（Apple Silicon / M 系列）：`uno-darwin-arm64`
- **直接使用仓库内 `dist/` 目录**里已构建好的二进制（若已提交）。
- **自行构建**（已安装 Go 工具链）看 [第 10 节](#10-自行构建)。

> 对局记录文件 `games.json` 会生成在**可执行文件所在目录**。

## 2. 快速开始（推荐：引导式启动）

直接运行 `./uno` 即可，程序会**一步步引导你**完成设置，不需要记任何参数：

```
$ ./uno
uno 1.4.0 — Terminal UNO

（括号内为上次的配置，直接回车即可沿用）
你的昵称（默认 Alice）:                            ← 回车=沿用上次
开房还是加入？[H]ost / [J]oin（默认 host）:        ← 回车=开房
监听端口（默认 7777）:                             ← 回车=7777
使用房间密钥文件吗？[y/N]（默认 n）:               ← 回车=无密钥
```

向导会依次询问：昵称 → 开房还是加入 → （开房）端口 / 是否密钥，或（加入）目标地址 / 密钥文件。全部回车即用默认值，随后自动进入游戏大厅。

**记得住你的配置**：你填写的昵称、模式、端口 / 目标地址、是否使用密钥会保存在可执行文件旁的 `uno-config.json`（仅当前用户可读写），下次启动会作为默认值显示，一路回车即可照旧开工。房间密钥**本身**从不写入此文件，只记住密钥文件路径。可用环境变量 `UNO_CONFIG=/path/to/config.json` 指定配置文件位置。

> 想加入别人房间时，在"开房还是加入"里输入 `j`，再填对方地址，例如 `192.168.1.10:7777`（端口缺省自动用 `7777`）。

在房间大厅按 `r` 准备。凑齐 2–4 人（其他人已准备）后，**房主按 `s` 开始游戏**。

## 2.1 进阶：直接命令（host / join）

想跳过向导、直接指定，也可以用子命令（缺省的 `--name` 会在终端里补问）：

```bash
./uno host --port 7777                          # 开房（名字会被询问）
./uno join 192.168.1.10:7777                    # 加入（名字会被询问）
```

程序会监听 `0.0.0.0:7777`，并打印出供队友连接的地址，例如 `192.168.1.10:7777`。

## 3. 使用房间密钥（可选）

想防止同网段无关玩家混入时，房主与所有加入端使用**同一个小密钥文件**：

```bash
# 房主：文件不存在会自动创建，并只在当前用户可读可写
./uno host --name Alice --room-key-file ./room.key

# 队友：必须使用同一份密钥文件（请通过私密渠道传递）
./uno join 192.168.1.10:7777 --name Bob --room-key-file ./room.key
```

> 密钥绝不会作为明文命令行参数，也绝不写入日志。请自行用加密/私密方式把 `room.key` 交给可信队友。

## 4. 命令行（可选的高级直连模式）

```
uno                 Guided, interactive startup (推荐，无需参数)
uno host [flags]    Host a room and join it as a player
uno join <ADDR> [flags]  Join a room (默认端口 7777)
uno help            Show this help
```

| 参数（host/join 可选） | 说明 |
|---|---|
| `--name string` | 玩家名（1–24 字符；省略时会在终端里询问） |
| `--port int` | 房主监听端口（默认 `7777`） |
| `--room-key-file path` | 启用密钥入场：host 创建/读取，join 读取；默认无密钥 |

退出游戏：在**主界面**按 `q`。`q` 同时在各类次级界面（帮助、规则、历史）里作为“返回”键，防止误退。

## 5. 游戏界面与快捷键

### 界面构成

- 顶部：房间与玩家列表（含每位玩家的手牌数、准备/断线/UNO 状态）。
- 中部：轮到谁、当前方向、桌面顶牌与当前颜色。
- 底部：你的手牌。**轮到你的回合时，手牌会用高亮边框框起来**提醒你行动。
- **轮到你（或需作 +4 接受/挑战决定）时，终端会响铃提醒**（BEL `\a`；具体是否出声取决于终端铃声设置）。**有玩家加入大厅时也会响铃**提示。

- 最底部：当前可用的按键提示。

### 快捷键速查

| 场景 | 键位 | 作用 |
|---|---|---|
| 通用 | `h` / `?` | 打开/关闭帮助 |
| 通用 | `q` | 返回上一级；主界面时退出 |
| 通用 | `l` | 离开房间 |
| 大厅 | `r` / 空格 | 准备 / 取消准备 |
| 大厅（仅房主） | `s` | 全部就绪后开始游戏 |
| 你的回合 | `1-9` / `0` | 打出对应序号的手牌 |
| 你的回合 | `d` / 空格 | 摸一张牌 |
| 摸牌后 | `p` | 打出刚摸到的牌 |
| 摸牌后 | `g` | 保留刚摸的牌，结束回合 |
| 万能牌选色 | `r` / `y` / `g` / `b` | 选 红/黄/绿/蓝 |
| 万能牌选色 | `q` | 取消出牌，牌留在手里 |
| 被罚 +4 | `c` | 挑战对方 |
| 被罚 +4 | `a` | 接受，摸 4 张（默认跳过） |
| 任意界面 | `v` | 查看当前规则（房主按 `e` 进入编辑） |
| 任意界面 | `t` | 查看本机对局记录 |
| 对局结束 | `b` | 返回大厅，再开一局（无需退出程序） |

> 出牌合法性一律由**服务端**裁决；非法操作只会得到提示，不会破坏牌局。

### 显示辅助

- 提示文字省略号 `…` 代表可继续滚动。
- `NO_COLOR=1` 可关闭颜色。
- 窗口太窄时自动切换紧凑单行手牌；不支持 Unicode 的终端自动改用 ASCII 符号。

## 6. 玩法与规则速查

标准经典 108 张牌，2–4 人，每人开局 7 张，无 +2/+4 叠加。

| 牌 | 效果 |
|---|---|
| 数字牌 | 普通出牌，轮到下一位 |
| 跳牌 | 下一位被跳过 |
| 反转 | 改变出牌方向（2 人局相当于跳过自己） |
| +2 | 下一位摸 2 张并跳过回合 |
| 万能 | 你指定接下来的颜色 |
| +4 | 你指定颜色，且下一位摸 4 张（可被挑战） |

- **自动 UNO**：手牌只剩 1 张时自动标记 UNO，无需手动喊。
- **+4 挑战**：被 +4 时，若你怀疑对方出 +4 前手里其实有当前颜色的牌，可按 `c` 挑战；判对方违规则对方摸 4 张，否则你摸 6 张。
- **惩罚叠加（+2 叠加 / +4 叠加 / 混合叠加）**：房主开启后，被 +2 攻击的玩家可出另一张 +2（+4 叠加可出 +4；混合叠加可 +2/+4 互接）把惩罚继续累加，惩罚值累积；无牌可接时选择接受并摸累计张数、跳过回合。+4 叠加可与 +4 挑战共存（合并规则）：叠加堆中最近一张是 +4 时，受罚玩家可挑战该 +4——若其违规，该 +4 撤销（惩罚 −4）并让其摸 4；否则挑战者摸取整个叠加堆。
- **积分赛（win_mode=SCORE）**：房主可把胜负模式设为“积分赛”。每局（回合）结束时，获胜者获得所有对手剩余手牌的分值（数字=面值，跳/反转/+2=20，万能/+4=50）；同时每位未获胜玩家按自己手中剩余牌的分值**扣分**（可为负）。逐局累计；率先达到目标分（默认 500，可设 100～2000）者夺冠。游戏会在一局结束后自动开始下一局，界面顶部显示当前局数与各玩家累计积分（结束时也提示每人+/-变动）。
- 细节与可选房规见 [rule.md](rule.md)。

规则页（按 `v`）会列出当前生效的每一条规则和每张功能牌的作用。

## 7. 房主设置规则

1. 开局前按 `v` 打开规则页。
2. 房主再按 `e` 进入规则编辑。
3. 用 `↑`/`↓`（或 `k`/`j`）选择项目，`←`/`→`（或 `+`/`-`）/空格 改变值。
4. 按 `s` 保存并广播给所有玩家；按 `q`/`v`/`esc` 返回。

可设置项：最大人数、初始手牌数、初始方向、先手规则、胜负模式（单局/积分赛）、目标积分，以及 跳牌/反转/+2/万能/+4/+4 挑战/动作牌可收尾/+2 叠加/+4 叠加/混合叠加/自动 UNO 的开关。

> 规则在**开局时锁定**，游戏中不能再改；规则变更会实时同步给所有玩家。

## 8. 对局记录（排查用）

每局结束会自动把结果记录到**可执行文件同目录**的 `games.json`，主要用于排查 bug：

- 记录胜者、结束原因、规则版本、每位玩家最终手牌数。
- 记录**完整的事件时间线**（出牌/摸牌/跳/反转/挑战等），可逐局回放。
- 在 TUI 里按 `t` 查看历史列表，按 `1-9`/`0` 展开某一局的详细回放，`q` 逐级返回。
- 直接打开 `games.json` 也可阅读完整原始记录（仅含玩家名与手牌数，不含他人手牌内容）。

## 9. 联网与防火墙

- 房主监听 `0.0.0.0`。**跨机器**需在房主机器上放行所用 TCP 端口（如 `7777`）。
- 同一局域网内的玩家直接连接房主的局域网 IP。
- 跨网络（外网）玩家：各自加入同一个 **ZeroTier** 虚拟网络后，用房的 ZeroTier IP 连接房主（如 `10.147.0.2:7777`）。ZeroTier 只提供 IP 层连接，不参与游戏协议。
- 只有加入了同一网络、且持有相同房间密钥（若启用）的玩家能加入。

## 10. 自行构建

```bash
go build -o uno ./cmd/uno                                  # 当前平台
GOOS=windows GOARCH=amd64 go build -o uno.exe ./cmd/uno    # Windows
GOOS=darwin  GOARCH=arm64 go build -o uno-darwin ./cmd/uno # macOS (Apple Silicon)
GOOS=linux   GOARCH=amd64 go build -o uno-linux ./cmd/uno  # Linux
```

## 11. 常见问题

| 现象 | 处理 |
|---|---|
| 连不上/连接被拒 | 确认房主已 `host`、端口一致、防火墙已放行端口 |
| `AUTH_FAILED` | 房间密钥不匹配，或重连 token 已失效 |
| `ROOM_FULL` | 房间已满（最多 4 人） |
| 断线后等待 | 房主进程结束、或 5 秒宽限期结束前，可凭重连 token 自动恢复 |
| 手牌序号/快捷键 | 手牌按原始顺序稳定显示，数字键对应行号 |
| 规则为什么不能编辑 | 游戏开始后规则已锁定，需在开局前设置 |
| `games.json` 在哪 | 在可执行文件同一目录下 |
